# Amazon Brazil E-Commerce SQL Analysis

## Project Overview

A SQL-based case study analyzing Amazon Brazil e-commerce data to uncover insights into customer behavior, sales, products, orders, sellers, and payment patterns.

The project is designed from an Amazon India business perspective to identify customer and market insights from the Brazilian e-commerce dataset.

## Objectives

- Analyze customer purchasing behavior
- Identify payment preferences and patterns
- Analyze product and category performance
- Identify sales and seasonal trends
- Segment customers based on purchase frequency
- Identify high-value customers and products

##  Tools & Technologies

- MySQL
- MySQL Workbench

##  SQL Concepts Used

- Joins
- Aggregations
- CASE statements
- Subqueries
- CTEs
- Window Functions
- Recursive CTEs
- Date Functions
- Customer Segmentation
